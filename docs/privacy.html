Privacy Policy

Last updated: 12 November 2026

YT Automation ("the app") is a personal tool used only by the owner of the YouTube channel EXTREME EARTH LIFE to upload that channel's own videos.

What the app accesses

With the owner's permission (Google sign-in), the app uses these YouTube Data API scopes:

  • youtube.upload – to upload videos to the owner's channel as private, optionally scheduled to publish later;
  • youtube.readonly – to confirm which channel is connected and that an uploaded video is private.

What is stored

The only data kept is the OAuth refresh token for the owner's own account, stored privately by the owner (on their own computer and as an encrypted secret in their private code repository) so uploads can run automatically. Video files, titles and descriptions are created by the owner. No data about any other person is collected.

Sharing

No data is sold, shared or transferred to anyone. Data is sent only to Google/YouTube to perform the uploads the owner requests.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube data is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions or Google security settings. Revoking it makes the stored token useless.

Contact

Questions: use the contact details on the EXTREME EARTH LIFE channel's About page on YouTube.
